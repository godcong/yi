# 数理简介

周易的核心是一套从阴阳到卦象再到数理的推演系统。本文梳理本项目中的数理链路及其实现约定。

## 阴阳与位约定

一切始于阴阳两仪：

| 概念 | 符号 | 本项目 bit 表示 |
|------|------|-----------------|
| 阳（阳爻） | ━━━ 实线 | **0** |
| 阴（阴爻） | ━ ━ 虚线 | **1** |

> **重要约定**：本项目记阳为 0、阴为 1。这与直觉中"阳=1"相反，但与二进制位逻辑一致：阴爻存在记 1，不存在记 0。

此约定贯穿整个库——从八卦的 3-bit 编码到六十四卦的上下卦组合，均以此为基准。

```go
// 八卦的二进制表示
Qian = 0b000  // 乾：三阳爻
Kun  = 0b111  // 坤：三阴爻
Kan  = 0b101  // 坎：上下阴中间阳
```

## 四象

两仪之上叠加一层阴阳，得四象：

| 四象 | 下爻 | 上爻 | 含义 |
|------|------|------|------|
| 太阳 | 0 (阳) | 0 (阳) | 阳+阳 |
| 少阴 | 0 (阳) | 1 (阴) | 阳+阴 |
| 少阳 | 1 (阴) | 0 (阳) | 阴+阳 |
| 太阴 | 1 (阴) | 1 (阴) | 阴+阴 |

在铜钱法中，四象对应四种爻值：9=老阳(变)、8=少阳、7=少阴、6=老阴(变)。

## 八卦

三条线（三爻）组合，得八个卦象，即八卦。每卦由 3-bit 二进制表示：

| 卦 | Bit | 十进制 | 符号 | 象 |
|------|------|------|------|------|
| 乾 | 000 | 0 | ☰ | 天 |
| 兑 | 001 | 1 | ☱ | 泽 |
| 离 | 010 | 2 | ☲ | 火 |
| 震 | 011 | 3 | ☳ | 雷 |
| 巽 | 100 | 4 | ☴ | 风 |
| 坎 | 101 | 5 | ☵ | 水 |
| 艮 | 110 | 6 | ☶ | 山 |
| 坤 | 111 | 7 | ☷ | 地 |

### 先天八卦与后天八卦

**先天八卦**（伏羲八卦）：以乾坤为南北，取自然对立之序。本项目八卦常量 `Qian=0…Kun=7` 即先天序。

**后天八卦**（文王八卦）：在八卦基础上加入"中"位，成为**九象**。后天序的数字发生了变化，其变化原因与"矩"的平衡性有关。

## 六十四卦

八卦再叠一层——上卦 + 下卦 = 六十四卦：

- 上卦（外卦）：第 4、5、6 爻（四爻、五爻、上爻）
- 下卦（内卦）：第 1、2、3 爻（初爻、二爻、三爻）

8 × 8 = 64 种组合，对应《周易》六十四卦。

```go
// 按数起卦：上卦=乾(0), 下卦=坎(5)
zy := yi.DivineByNumber(0, 5)  // 天水讼
fmt.Printf("卦名: %s\n", zy.GetGua(yi.Ben).Ming)
```

### 卦象变换

一个本卦可以衍生出四种变换卦象：

| 变换 | 名称 | 方法 | 用途 |
|------|------|------|------|
| 本卦 | Ben | 原始起卦结果 | 当前状态 |
| 变卦 | Bian | 动爻取反 | 事物发展趋势 |
| 互卦 | Hu | 取2-3-4为下卦，3-4-5为上卦 | 中间过程 |
| 错卦 | Cuo | 阴阳全部取反 | 对立面 |
| 综卦 | Zong | 上下颠倒（反转bit顺序） | 换位思考 |

```go
zy := yi.DivineByNumber(0, 0, 0)  // 乾为天，动爻在初爻
fmt.Printf("本卦: %s\n", zy.GetGua(yi.Ben).Ming)   // 乾为天
fmt.Printf("变卦: %s\n", zy.GetGua(yi.Bian).Ming)   // 天风姤
fmt.Printf("互卦: %s\n", zy.GetGua(yi.Hu).Ming)     // 乾为天
fmt.Printf("错卦: %s\n", zy.GetGua(yi.Cuo).Ming)    // 坤为地
fmt.Printf("综卦: %s\n", zy.GetGua(yi.Zong).Ming)   // 乾为天
```

## 八十一象（矩）

八卦再由上下两卦生成八十一象，称为"矩"。八十一与《老子》《道德经》八十一章相对应。

关于八十一象的详述，参见 [《八卦九象和〈老子〉的创作方法、分章及章序》](https://zhuanlan.zhihu.com/p/90606767)。

本项目以"大衍之数"冠名 81 数理系统，用于姓名笔画吉凶分析。

```go
dayan, _ := yi.GetDayan(1)
fmt.Printf("第1数: %s\n", dayan.JiXiong)  // 吉
fmt.Printf("含义: %s\n", dayan.Meaning)
```

## 动爻与变卦

任何一个数对 6 取余（得 0 者记为 6），得六爻之变数。对原有卦象取爻变（对应爻取反），即得变卦，通常预示着所占卜之事的最终结果。

```go
// DivineByNumber 第三个参数指定动爻位置（0-5）
zy := yi.DivineByNumber(0, 0, 2)  // 乾为天，动爻在三爻
bianPos := zy.GetBianYao()
fmt.Printf("动爻位置: %d\n", bianPos)
```

## 数理链路总结

```
阴阳 (0/1)
  ↓ 叠加
四象 (2-bit)
  ↓ 叠加
八卦 (3-bit, 8种)
  ↓ 上卦×下卦
六十四卦 (64种)
  ↓ 8×8+中位
八十一象/矩 (81种) ← 对应《老子》81章
```

每一步都是前一步的组合与叠加，构成了从最简单的阴阳到最复杂的八十一象的完整数理体系。
